# 심우현 개발자 포트폴리오

[심우현 개발자 포트폴리오](https://simwoohyun.vercel.app)는 React 프론트엔드, FastAPI, RAG 기반 AI 검색, AI Agent 개발 경험을 정리한 개인 포트폴리오 사이트입니다.

## 포지션

**Front-End Engineer & AI Agent Engineer**

- React, TypeScript, Next.js 기반 사용자 화면 설계
- FastAPI, PostgreSQL, REST API 기반 데이터 흐름 구현
- RAG Pipeline, BM25 + Vector Search, Pinecone 기반 AI 검색 서비스 개발
- 문제 재현, 문서화, 테스트, 배포까지 고려한 서비스 개선
